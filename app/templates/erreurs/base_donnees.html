La base de données n'est pas à jour

L'application a demandé à la base une information que celle-ci ne connaît pas encore. Cela signifie presque toujours que le code a évolué mais que les migrations n'ont pas été appliquées — par exemple après avoir récupéré une nouvelle version du projet.

Comment corriger

Depuis le dossier du projet, l'environnement virtuel activé :

flask db upgrade

Puis relancez l'application. Si le problème persiste, vérifiez que la variable FLASK_APP vaut bien wsgi.py.

Autres causes possibles

  • Le serveur de base de données est momentanément injoignable.
  • La variable DATABASE_URL pointe vers une base inexistante.
